# お米受注管理（iPhone用アプリ）

お米の受注・送料計算・ステータス管理・領収書発行を行う iPhone 用アプリです。
Safari の「ホーム画面に追加」でアプリとして使えます（App Store・Mac 不要、オフラインでも動作）。

## 主な機能

- **発注者**：初回は手入力、2回目以降はドロップダウンで選択。都道府県・住所・郵便番号・電話番号が自動で入り、受注画面で直した内容は発注者情報にも反映されます。都道府県はドロップダウン選択。
- **郵便番号から住所を自動入力**：7桁を入れると都道府県と住所（町域まで）が入ります。郵便番号データ（日本郵便）は `zip/` にアプリと一緒に置いてあり、外部の検索サービスは使いません（出典：[yubinbango-data](https://github.com/yubinbango/yubinbango-data)）
- **ハイフン入力**：郵便番号・電話番号の横の「－」キーでハイフンを入れられます。郵便番号と携帯電話番号は自動でハイフンが入ります
- **ご注文内容**：精米／玄米 × 5kg・10kg・30kg の袋数を ＋／− で入力
  - 1袋の価格は設定画面で入力します（価格はプログラムに含まれず、iPhone内に暗号化して保存。変更しても登録済み受注の金額は変わりません）
- **送料**：佐川急便 飛脚宅配便・熊本県（南九州）発の運賃を、届け先の都道府県から自動計算
  - 箱の重さ上限：80サイズ＝5kg／100サイズ＝10kg／140サイズ＝20kg／160サイズ＝30kg
  - 「袋をまとめて梱包する」（初期設定）では、送料が一番安くなる箱の組み合わせを自動で選びます（例：5kg＋10kg＝15kg → 140サイズ1個、5kg×7袋 → 160サイズ1個＋80サイズ1個）。チェックを外すと1袋＝1個口
  - 沖縄県は自動計算の対象外（送料を手入力）
  - 送料表は設定画面で編集できます。手入力に切り替えることもできます
- **ステータス**（日付から自動判定）
  - 総額連絡日を入力 →「出荷準備中」（未入力は「総額未連絡」）
  - 発送日を過ぎる →「発送済み」（未来の日付は「発送予定」として表示）
  - 入金確認日を入力 →「入金済み」、それまでは「入金待ち」
- **総額連絡**：注文内容・送料・合計（・振込先）のメッセージを作成し、LINE／メッセージ／メールで送れます
- **領収書**：宛名・発行日・但し書き（受注内容）を確認して印刷／PDF保存。**消費税の記載はありません**（免税事業者向け）。発行者名・住所・電話番号は設定で編集
- **領収書の写真**：稲穂などの写真を領収書の背景（うすく）または上部の帯に入れられます。写真は端末内に暗号化して保存し、毎年差し替えできます
- **生産者写真**：顔写真や作業風景を領収書の発行者名の横に入れられます（丸／四角）。枠の中でドラッグ・ピンチ・スライダーで位置と大きさを調整でき、後から調整し直せます
- **暗号化保存**：データはすべてこの iPhone 内（IndexedDB）に、パスコードから作った鍵（PBKDF2-SHA256 60万回 → AES-256-GCM）で暗号化して保存。外部への送信は一切ありません
- **自動ロック**・**暗号化バックアップの書き出し／復元**

## iPhone への入れ方

1. GitHub のこのリポジトリで **Settings → Pages → Source を「GitHub Actions」** にし、`main` ブランチに反映すると自動で公開されます（`.github/workflows/pages.yml`）。
   公開されるのはアプリのプログラムだけで、受注データは含まれません。
2. iPhone の **Safari** で公開URL（`https://<ユーザー名>.github.io/rice-sell-management-tool/`）を開く
3. 共有ボタン →「ホーム画面に追加」
4. ホーム画面のアイコンから起動し、パスコードを設定
5. 設定画面でお米の価格・発行者情報・振込先を入力

> ホーム画面に追加したアプリとして使ってください。Safari のタブのままだと、しばらく使わないとデータが消されることがあります。
> 機種変更や万一に備え、ときどき「設定 → バックアップを書き出す」でファイルに保存してください。

## 開発

ビルド不要の素の HTML / CSS / JavaScript です。

```sh
python3 -m http.server 8000   # http://localhost:8000 で動作確認
```

- `js/app.js` 画面と操作
- `js/data.js` 都道府県・地域区分・価格・送料の初期値
- `js/vault.js` 暗号化ストレージ
- `sw.js` オフライン用キャッシュ
